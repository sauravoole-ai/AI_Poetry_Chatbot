# 🌌 AI Poetry Chatbot

An AI-powered poetry generation web application built with **Flask** and **Groq API**, allowing users to generate mood-based poems instantly through an interactive web interface.

## 🌐 Live Demo

https://ai-poetry-chatbot.onrender.com

## 💻 GitHub Repository

https://github.com/sauravoole-ai/AI_Poetry_Chatbot

## ✨ Features

- 🎭 AI-generated poetry based on selected mood
- 🌙 Multiple mood options for personalized output
- ⚡ Fast response generation using Groq API
- 📄 Download generated poems as PDF
- 🎨 Responsive and interactive frontend
- ☁️ Deployed on Render

## 🧠 Tech Stack

- 🐍 Python
- ⚙️ Flask
- 🧠 Groq API / Llama 3.1 8B Instant
- 🎨 HTML, CSS, JavaScript
- 📄 ReportLab
- 🚀 Gunicorn
- ☁️ Render
